# Self-hosted font credits

Every typeface in this folder is released under the **SIL Open Font License 1.1**
(https://openfontlicense.org/), which permits free use, web embedding and
redistribution. The licence text, with each font's copyright notice, sits next to the
font files as `<slug>/OFL.txt`. Reserved Font Names belong to their authors. These are
unmodified copies, apart from renaming the files.

Font files were downloaded on 2026-10-30 from the source given for each font. The
"Licence verified at" column shows where the licence was checked.

## Licence-file notes

- **Bluu Next**: the upstream `OFL.txt` is UTF-16; it was converted to UTF-8 and the text is unchanged.
- **Terminal Grotesque, Office Code Pro, Blocks on Blocks**: no usable upstream licence file was available. The upstream Terminal Grotesque `LICENSE.md` names the wrong font, Office Code Pro's original repository is gone, and Blocks on Blocks states "OFL" only in its README. For these three, `OFL.txt` contains the standard SIL OFL 1.1 text and a header naming the authors and the place the licence was verified.
- **Frick, Rag, Sunday Masthead**: the upstream OFL.txt files still have the template copyright line. They are copied as published.

Google Fonts families are loaded from fonts.googleapis.com and are not stored in this folder.
